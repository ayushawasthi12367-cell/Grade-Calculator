# Grade-Calculator


A simple Python console program that takes a numeric grade as input and returns the corresponding letter grade along with a short motivational message.

Features
Accepts a numeric grade (0–100) as input
Classifies the grade into a letter grade band:
A grade: 80–100
B grade: 60–79
C grade: 50–59
Fail (repeat exam): 40–49
Fail (repeat course): 0–39
Displays an encouraging message alongside each result
Validates input range and shows an error message for grades outside 0–100
How it works
Run the script.
Enter a numeric grade when prompted.
The program evaluates which grade band it falls into.
It prints your letter grade along with a relevant message.
